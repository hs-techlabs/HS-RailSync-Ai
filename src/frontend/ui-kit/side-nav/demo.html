Floating Side Nav

Hover the rail on the left. Groups expand into subpages; collapsed, they open as flyouts. Pin it with the tab on the panel edge.

Live controls

Minimum integration

<link rel="stylesheet" href="/static/ui-kit/side-nav/side-nav.css">
<script src="/static/ui-kit/side-nav/side-nav.js"></script>
<script src="/static/ui-kit/side-nav/nav.config.js"></script>
<script>
  const nav = SideNav.create(NAV_PRESETS.tms);
</script>

Active page is derived from location.pathname (and #hash when the item carries one), so no per-page flag is needed.

Defining pages & subpages

{
  id: 'corridor',                 // stable id — used by setActive/updateItem
  label: 'Corridor View',
  icon: 'map',                    // built-in name, raw <svg>, image URL, or emoji
  defaultOpen: true,
  children: [                     // ← subpages, nested to any depth
    { id: 'corridor-map',   label: 'Network Map',   href: '/#corridor-map' },
    { id: 'corridor-marey', label: 'Marey Diagram', href: '/#marey' }
  ]
}
